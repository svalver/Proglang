
# ProgLang


This public repository contains historical materials accompanying our 2015 study of how
programming languages evolve. If do you find anything useful please consider citing our
publication: 

Valverde, S. and Solé, R.V. (2015). "Punctuated equilibrium in the large-scale evolution of programming languages." *Journal of the Royal Society Interface*, 12(107), 20150249. https://doi.org/10.1098/rsif.2015.0249.

Network visualizations of programming languages can be found on: __https://svalver.github.io/Proglang/__
